# KPI Definitions

| KPI | Definition |
|---|---|
| Recommendation Accuracy | Percentage of AI-assisted recommendations accepted as correct after validation |
| Human Override Rate | Percentage of recommendations changed by a human |
| Automation Success Rate | Percentage of eligible automations completed successfully |
| SLA Compliance | Resolved tickets completed within target SLA |
| MTTR | Average resolution time for resolved/closed tickets |
| First Contact Resolution | Percentage resolved during the initial support interaction |
| Reopen Rate | Percentage of resolved/closed tickets later reopened |
| Escalation Rate | Percentage requiring escalation beyond the initial assignment group |
| User Satisfaction | Synthetic CSAT value captured after resolution |

## Management Interpretation

No single KPI should be optimized in isolation.

For example, a reduction in MTTR is not automatically positive if reopen rate or user dissatisfaction increases. Automation should therefore be evaluated against service quality, risk, control effectiveness and business impact.
