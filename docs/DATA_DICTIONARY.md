# Data Dictionary

| Field | Description |
|---|---|
| Ticket ID | Synthetic unique incident identifier |
| Created Date | Date the ticket was created |
| Created Time | Time the ticket was created |
| Department | Simulated requester department |
| Location | Simulated operating location |
| Service | IT service associated with the ticket |
| Category | Synthetic business/technical category |
| Subcategory | More specific ticket classification |
| Description | Synthetic user-provided problem statement |
| Impact | Simulated business impact: High, Medium, Low |
| Urgency | Simulated urgency: High, Medium, Low |
| Policy Priority | Priority derived from impact and urgency |
| Assignment Group | Recommended resolver group |
| SLA Target Hours | Target resolution time for the policy priority |
| Resolution Hours | Synthetic elapsed resolution time |
| Status | Open, In Progress, Resolved, or Closed |
| AI Category | Recommended classification |
| AI Category Confidence | Confidence score for category recommendation |
| AI Priority | Recommended priority |
| AI Priority Confidence | Confidence score for priority recommendation |
| Knowledge Article ID | Suggested approved knowledge article |
| Human Approval Required | Whether the action must be reviewed |
| Automation Eligible | Whether the action passes governance rules |
| Automation Action | Proposed automation action |
| Automation Result | Simulated outcome of governance evaluation |
| Reopened | Synthetic reopened-ticket indicator |
| User Satisfaction | Synthetic 1–5 satisfaction score |
